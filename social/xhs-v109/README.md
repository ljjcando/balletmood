# Ballet Mood v1.0.9 小红书海报存档

## 用途

本目录保存 Ballet Mood v1.0.9 发布后使用的小红书六张轮播海报，便于以后回看版本内容和继续修改。

## 可追溯文件

- `index.html`：海报的完整源文件，是文案和版式的最终依据。
- `output/`：导出的 PNG 图片。PNG 属于可重新生成文件；如与源文件存在差异，以 `index.html` 为准。
- 小程序 v1.0.9 运行代码：Git 提交 `54d8785`。
- v1.0.9 发布记录与最初海报源文件：Git 提交 `e60aeed`。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 8899 --bind 127.0.0.1
```

然后访问：

`http://127.0.0.1:8899/social/xhs-v109/`
